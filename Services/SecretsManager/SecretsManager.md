# Secrets Manager

* Purpose: protect and store secrets in central location


### Features

* rotate secrets without code deployment
* control access to secrets with permissions
* encryption with AWS KMS 

### Secrets Types

* RDS Database
* Redshift Cluster
* DocumentDB Database
* other databases
* API keys

### Info stored in secrets

* credentials: username, password
* server address for databases
* database name and port
