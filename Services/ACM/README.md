# AWS Certificate Manager (ACM)
* create and manage public and private certificates:
    * Secure Sockets Layer (SSL) certificates
    * Transport Layer Security (TLS) certificates

### Features

### Restrictions
* certificates must be created in us-east-1 when using ACM with Cloudfront

## Background Info

### What are SSL and TLS certificates?
* digital certificates that verify authenticity of website
* used to enable secure connection between visitors and website using HTTPS

### How do the SSL and TLS certificates work?
* the certificates are used to encrypt visitor data

### When do you need an SSL or TLS certificate on AWS?
* when you're using your own domain name for a website hosted by AWS
