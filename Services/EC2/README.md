# EC2 (Elastic Compute Cloud)

### Whats
* secure, resizable compute capacity in AWS
* like a virtual machine or server, but hosted on AWS on a public cloud

### Pros
* pay for only the computing capacity you need
* can scale capacity almost immediately, according to demand

### Pricing Options (Ordered by Most Expensive)

| Pricing Option | Pricing | Description | Best Use Case |
|----------------|---------|-------------|---------------|
| Dedicated | Most expensive | get your own physical server| |
| On Demand | charged by hour or second | pay by hour or second | apps that are short-term, fluctuating workloads, testing new apps|
| Reserved | up to 72% discount on hourly charge | buy a certain amount of capacity for 1-3 years | |   
| Spot | up to 90% discount on hourly charge; fluctuate with supply and demand | buy unused capacity, set max price for instance that would get terminated once price exceeded | |
