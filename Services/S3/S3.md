# S3 (Simple Scalable Storage)

### Purpose
* secure, scalable object-based storage

### General features
* designed for 99.95-99.99% availability, depending on s3 tier
* designed for 11 9's durability for data storage (99.999999999%)
    * can expect to lose an object every 10,000 years
* lifecycle management: can automatically delete objects or move them to different storage tiers
* server-side encryption
* access control lists for AWS accounts and groups
* bucket policies: specify what actions are allowed or denied 


### Storage features
* unlimited storage
* object-based
    * objects stored in "buckets"
    * objects have a key-value store
        * name of object is the **key**
        * data itself is the **value**
    * each object has a version id
    * versioning allows for retireving old versions, or rolling back to previous versions (including deleted objects)
    * each object has metadata that you can configure e.g content-type, last modified date, tags
    * objects can be up to 5 TB in size
* universal namespace: all aws accounts share the s3 namespace
    * each s3 bucket name must be globally unique
    * buckets have their own urls e.g https://bucket-name.s3.us-east-1.amazonaws.com/key-name

## Storage Classes
* cost: S3 standard > S3 Intelligent Tiering > S3-IA > Glacier

| Storage Class | Availability | Retrieval Time | # availability zones | Minimum Storage | Use Case |
|---------------|--------------|----------------|----------------------|-----------------|----------|
| S3 Standard | 99.99% | immediate | >= 3 | None | most workloads with frequent access |
| S3 Infrequent Access | 99.9% | immediate | >= 3 | 30 days | long-term storage, backups, disaster recovery|
| S3 One Zone-Infrequent Access | 99.5% | immediate | 1 | 30 days | infrequently accesed, non-critical data|
| S3 Glacier Instant
| S3 Glacier Flexible Retrieval | 



### S3 One Zone Infrequent Access
* data stored redundantly in one availability zone
* minimum storage duration: 30 days
* cost 20% less than S3-IA
* availability: 99.5%
* better for noncritical data

### Glacier
* optimized for very infrequently accessed data: pay per retrieval for lower storage fee
* use: archive
* **glacier instant retrieval**
    * long-lived data accessed about once per quarter
    * data requires millisecond retrieval time
    * minimum storage 90 days
    * availability: 99.9%
* **glacier flexible retrieval**
    * retrieval within minutes or hours
    * minimum storage: 90 days
    * availability: 99.99%
* **glacier deep archive**
    * default retrieval time: 12 hours
    * minimum storage duration: 180 days
    * availability: 99.99%

## S3 Intelligent Tiering
* automatically moves data between S3 standard and S3-IA 
* helps with cost-effectiveness
